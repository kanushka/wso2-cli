WSO2 CLI
Install Commands GitHub

One command line
for every WSO2 product.

Install once, sign in once, then work with every WSO2 product from the terminal, with the same commands, flags and output for each of them.

Install

macOS, Linux, WSL 
$ curl -fsSL https://wso2.github.io/wso2-cli/install.sh | bash
Windows 
> iwr https://wso2.github.io/wso2-cli/install.ps1 -useb | iex

Checksum verified, no admin rights, nothing outside your WSO2 state root. Read the script before you run it.

First run

$ wso2 login
$ wso2 product available

The browser opens for the login, and that one login covers every product the list shows.
